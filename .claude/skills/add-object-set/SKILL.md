# Новый набор предметов («уровень») в Drummer Cat

Уровень в игре — это «набор» (`ObjectSet`): локация с фоном и десятью предметами, которые кот сбивает со стола. Набор состоит из файла данных `src/content/sets/<id>.ts`, спрайта предметов `src/content/svg/<id>.svg` (символы `#obj-<objId>`, 200×200), символа фона `#bg-<id>` (360×640) и регистрации в четырёх местах: `SetId` (`types.ts`), белый список `normalizeSave` (`core/store.ts`), массив `SETS` (`sets/index.ts`), импорт спрайта в `main.ts`. Шесть существующих наборов (`kitchen`, `desk`, `living`, `spacebase`, `magic`, `detective`) и таблицы в SPEC.md §7.2 и §20.2 — образец того, как это должно выглядеть.

## Порядок работы

### 1. Придумай состав

Прежде чем трогать код, составь таблицу набора в стиле SPEC §7.2. Ритм задаёт движок: каждый 10-й предмет в сессии — многоударный (`hp ≥ 2`), каждый 30-й — босс (`hp = 5`), поэтому у набора должен быть ровно такой состав:

| Сколько | hp | weight | size | Роль |
|---|---|---|---|---|
| 6 | 1 | 10 (один — 8, для разнообразия) | S (иногда M) | мелочь, основной поток |
| 2 | 2 | 5 | M | «тяжёлые», один слой повреждений |
| 1 | 3 | 3 | L | крупный, два слоя |
| 1 | 5 | 1 | L | босс, четыре слоя |

Для каждого предмета: `id` (латиница), `name` (кириллица), `hp`, `size` (ширина в viewBox 200: S ≤ 90, M ≤ 130, L ≤ 180 px; `L` ещё даёт тяжёлую хаптику при сносе), `breakable` (летят ли осколки), `hitText` (надпись при сносе, см. `references/object.md`), `sfx` (один из шести синтезированных звуков), `color` (основная заливка — им красятся осколки). Порядок в массиве важен: карточка набора в шторке показывает `objects[0]`, `objects[6]` и `objects[9]`, то есть первый мелкий предмет, первый «тяжёлый» и босса — ставь на эти места самые узнаваемые.

Название набора — 1–2 слова («Космобаза»), описание — три предмета через запятую («Кружки, тарелки и микроволновка»). `wallColor` — цвет стены, он же фон карточки набора.

### 2. Скаффолд

Запиши состав в JSON и отдай скрипту — так данные сразу попадут в `.ts` без ручной правки:

```bash
cat > /tmp/<id>-objects.json <<'JSON'
[
  { "id": "bottle", "name": "Бутылка рома", "hp": 1, "size": "S", "breakable": true, "hitText": "ДЗЫНЬ", "sfx": "glass", "color": "#5B8C3A" },
  ...
  { "id": "chest", "name": "Сундук", "hp": 5, "size": "L", "breakable": false, "hitText": "БА-БАХ", "sfx": "crash", "color": "#8D5524" }
]
JSON
node .claude/skills/add-object-set/scripts/scaffold-set.mjs <id> --name "Название" --desc "Описание" --wall #hex --spec /tmp/<id>-objects.json
```

Поля `weight`, `size`, `hitText`, `sfx`, `breakable`, `color` можно опустить — подставятся значения по умолчанию для данного hp. Быстрый вариант без JSON: `--objects id1,...,id10` (hp по ритму 6×1, 2×2, 1×3, 1×5; явно — `id:hp`), затем поправить имена и поля в `.ts`.

Скрипт регистрирует набор во всех четырёх местах, создаёт `sets/<id>.ts` и `svg/<id>.svg` с заготовками-прямоугольниками (с уже размеченными слоями `--dmgN` по hp) и дописывает заготовку фона `#bg-<id>` в `backgrounds-themed.svg`. С `--dry-run` только покажет будущий `.ts`.

### 3. Нарисуй предметы

Замени каждую заготовку в `svg/<id>.svg` целиком, по `references/object.md`. Ключевое: предмет стоит на линии y=180, обводка 4 px `#1F1A17`, плоские заливки без градиентов и фильтров, не более трёх цветов плюс блик. Слои повреждений — группы `<g style="display:var(--dmgN,none)">`, N от 1 до hp−1: трещины, вмятины, отвалившиеся детали, у босса на последнем слое — искры/молнии. `ObjectView` включает их через CSS-переменную на `<use>` — классы внутрь `<use>` не проходят, поэтому именно `style="display:var(...)"`.

### 4. Нарисуй фон

Доработай `#bg-<id>` в `backgrounds-themed.svg` по `references/background.md`: стена (y 0–380) с 2–4 узнаваемыми деталями локации, затем столешница-трапеция — её геометрию (три фигуры в конце заготовки) не меняй, только материал и цвет.

### 5. Проверка

```bash
npm test            # tests/content.test.ts: регистрация, импорт спрайта, все символы найдены, слои --dmgN по hp, есть босс
npm run typecheck
```

Визуально: `npm run dev`, 🎨 → вкладка «Предметы» → карточка набора (стена + три предмета) → выбрать; потапать до босса (каждый 30-й) или временно проверить многоударные через `__dc.SETS` в консоли. Смотри, что предметы стоят на столе, не вылезают за столешницу, слои повреждений читаются, осколки нужного цвета. Без браузерного инструмента — попроси пользователя посмотреть и скажи, на что обратить внимание.

### 6. Документация

Добавь таблицу набора в SPEC.md (§7.2 для «бытовых», §20.2 для тематических) — SPEC в этом проекте считается источником правды о контенте.

## Один предмет в существующий набор

Скаффолд не нужен. Добавь `<symbol id="obj-<objId>" viewBox="0 0 200 200">` в `svg/<set>.svg` того же набора и запись в `sets/<set>.ts`. Помни про ритм: `hp` только из {1, 2, 3, 5}, `weight` по таблице выше, слоёв `--dmgN` ровно hp−1. Если добавляешь 11-й предмет, проверь, что индексы 0/6/9 в карточке по-прежнему показывают то, что нужно. `npm test` проверит символ и слои.

## Чего не делать

- Не класть символы нового набора в чужой спрайт и не забывать импорт: `tests/content.test.ts` проверяет, что каждый файл в `src/content/svg` импортирован в `main.ts`, а каждый `symbol` из данных существует.
- Не делать `hp` вне {1, 2, 3, 5} и набор без `hp 5`: без босса `chooseFor` в движке упадёт на запасную ветку, и 30-й предмет перестанет быть событием.
- Не использовать `id` предметов с дефисами или заглавными: id становится частью `#obj-<id>` и ключом в тесте.
