# Предмет: `<symbol id="obj-<id>" viewBox="0 0 200 200">`

## Геометрия и стиль

- Предмет стоит на линии **y = 180**, точка опоры — центр низа (100, 180). В сцене `<use>` размещается так, что (100,180) попадает в `OBJ_BASE = (180, 480)` на столешнице; наклон при повреждении и сплющивание идут вокруг этой точки.
- Ширина по `size`: S ≤ 90, M ≤ 130, L ≤ 180 px. Высота свободна, но выше y ≈ 20 лучше не подниматься — пипсы HP и надпись удара рисуются рядом.
- Обводка `#1F1A17`, 4 px, `stroke-linejoin="round" stroke-linecap="round"` на общей группе. Плоские заливки, ≤ 3 цветов + белый блик (`stroke="#FFFFFF" stroke-width="5" opacity="0.4"`). Без градиентов, `filter`, растров, CSS-переменных для цвета.
- Силуэт следующего предмета показывается вдали через `filter="url(#silhouette)"` поверх `<use>`, поэтому форма должна читаться одним тёмным пятном: избегай тонких отдельно стоящих деталей, которые в силуэте превратятся в точки.
- `color` в `.ts` — основная заливка предмета: им красятся осколки при `breakable: true`. Для «жидких» предметов (кофе, зелье) — цвет жидкости.

## Слои повреждений

Для `hp > 1` внутри общей группы добавь ровно `hp − 1` групп:

```xml
<g fill="none" style="display:var(--dmg1,none)">
  <path d="M120 112 l10 12 l-8 12 l12 12 l-6 14"/>       <!-- трещина: ломаная -->
  <path d="M70 96 l8 -6 l10 6" stroke-width="3"/>        <!-- вмятина -->
</g>
<g style="display:var(--dmg2,none)">
  <circle cx="162" cy="132" r="10" fill="#F2F2F2"/>       <!-- отвалившаяся кнопка, лежит рядом -->
</g>
<g fill="#FFD400" style="display:var(--dmg4,none)">
  <path d="M150 60 l-8 14 h8 l-6 14 l14 -18 h-8 l6 -10 Z"/> <!-- искры/молния — только у босса на последнем слое -->
</g>
```

`ObjectView.applyDamage` ставит `--dmg1..--dmg4` в `inline`/`none` на `<use>`; слои включаются по одному с каждым ударом и накапливаются (на третьем ударе видны dmg1, dmg2 и dmg3). Поэтому каждый слой — это *новое* повреждение, а не перерисовка предмета. Хорошая прогрессия: трещина → вторая трещина и съехавшая деталь → отвалившаяся деталь → искры. Предмет при этом ещё и наклоняется на 4° за каждый потерянный HP — это делает код, в SVG наклон рисовать не надо.

## Таблица звуков `sfx` (Web Audio, синтез в `platform/audio.ts`)

| sfx | Как звучит | Для чего |
|---|---|---|
| `glass` | высокий звон из трёх синусов | стекло, хрусталь, экраны, колбы |
| `ceramic` | шумный «хрусь» с щелчком | керамика, фарфор, горшки |
| `thud` | низкий глухой удар | мягкое, деревянное, пластик, еда |
| `metal` | звенящий «брям» | металл, посуда, инструменты |
| `splash` | шум с низким «плюх» | жидкости, чашки с содержимым |
| `crash` | бум + шум + звон | крупное, босс, техника |

## Надписи `hitText`

Короткие (≤ 7 символов), заглавными, звукоподражания. Эффект сам увеличивает их с силой и добавляет «!». Привычные в проекте: ДЗЫНЬ (стекло), ХРУСЬ (хруст), ТУК (глухой стук), ШЛЁП (мягкое), ЧПОК, ПЛЮХ (жидкость), БРЯМ (металл hp2), ХРЯСЬ, БУХ, БАМ (hp3), БА-БАХ (босс), ЩЁЛК, КЛАЦ, ТРРР, ПШШ, ВЖИК, ДРЫНЬ, БОМ-М. Новые приветствуются, если читаются с первого взгляда.

    </g>
