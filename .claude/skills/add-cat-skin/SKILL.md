# Новый кот в Drummer Cat

Кот в игре — это шесть вещей: запись в `src/content/cats.ts`, палитра (по ней параметрически рисуется портрет в HUD и карточка в шторке), SVG-символ лапы `#paw-<id>` (240×320, вид сверху), стиль удара из `src/content/strikes.ts`, опциональный головной убор `accessory`, и регистрация id в `CatId` (`types.ts`) и в белом списке `normalizeSave` (`core/store.ts`). Шесть существующих котов — лучшая шпаргалка: `ginger` (базовый), `siam` (двухцветный с особыми случаями), `marine`/`wizard`/`sherlock` (тематические, с аксессуарами и предметами в лапе).

## Порядок работы

### 1. Реши, кто это

До правок зафиксируй (и, если пользователь оставил свободу, придумай сам, в духе проекта — плоский мультяшный стиль, толстая обводка `#1F1A17`):

- `id` — латиница в нижнем регистре без дефисов (`pirate`, не `pirate-cat`).
- `name` (1–2 слова, кириллица) и `description` — одна короткая фраза для карточки, как «Сыщик с Бейкер-стрит».
- Палитра из шести цветов: `fur` (основная шерсть: голова, лапа, шипы ярости), `fur2` (вторичный: полоски, пятна, маска), `eye` (радужка, на уровне 5 глаз заливается ею целиком), `nose`, `innerEar` (внутренняя часть уха — без аксессуара уши видны), `pad` (подушечки; сейчас на лапе не рисуются, но поле обязательно).
- Стиль удара: один из `StrikeId` в `strikes.ts`. Тесты требуют, чтобы у каждого кота стиль был **уникальным**, поэтому новый кот почти всегда означает новый стиль. Как его написать — `references/strike.md`.
- Предмет в лапе, который должен «срабатывать» при ударе (пепел, брызги) — это `impactFx` + `propTip` в стиле удара; статичный предмет (палочка, лупа, игрушка) — просто рисунок в лапе.
- `accessory`: нужен, если у кота что-то на голове или на морде. Шляпы рисуются вместо ушей и наклоняются с ростом ярости; очки, усы и причёски возвращают `keepEars: true`, и уши остаются.

### 2. Новый стиль удара — сначала

Если стиль новый, добавь его в `src/content/strikes.ts` (в `StrikeId`, константу и `STRIKES`) до запуска скаффолда: скрипт проверяет, что `--strike` существует. Контракт стиля проверяет `tests/strikes.test.ts`; подробности и шаблон в `references/strike.md`.

### 3. Скаффолд: регистрация во всех местах

```bash
node .claude/skills/add-cat-skin/scripts/scaffold-cat.mjs <id> --name "Имя" --desc "Описание" --strike <StrikeId> \
  [--accessory <helmet|wizard|deerstalker|новое-имя>] \
  --fur #hex --fur2 #hex --eye #hex --nose #hex --inner-ear #hex --pad #hex
```

Скрипт правит пять файлов и ничего не рисует:

| Файл | Что делает |
|---|---|
| `src/content/types.ts` | добавляет id в `CatId`; новое имя `accessory` — в его union |
| `src/core/store.ts` | добавляет id в белый список `normalizeSave`, иначе выбор кота сбрасывается на `ginger` после перезагрузки |
| `src/content/cats.ts` | добавляет запись с палитрой |
| `src/render/portrait.ts` | добавляет `case '<id>'` в `markings()` (switch исчерпывающий — без case `tsc` падает) и, для нового аксессуара, `case` в `accessory()` |
| `src/content/svg/paws-themed.svg` | добавляет заготовку `#paw-<id>` (этот файл уже импортируется в `main.ts`) |

Запусти с `--dry-run`, если хочешь сначала посмотреть запись. Всё, что нужно доделать руками, помечено `TODO(<id>)`.

### 4. Нарисуй лапу

Замени заготовку `#paw-<id>` в `paws-themed.svg` по `references/paw.md`. Главное ограничение: кисть должна остаться кругом около (78,78), а предплечье идти вправо-вниз к (270,420) — точки удара всех стилей (`impact` в `strikes.ts`) рассчитаны на эту геометрию, лапа другой формы будет бить мимо предмета. Декор (полоски, манжета, перчатка, предмет в лапе) — поверх слоя шерсти, когти — последними.

### 5. Нарисуй портрет

Открой `src/render/portrait.ts` и доработай `case '<id>'` в `markings()` (пятна, маска, полоски на лбу, светлая мордочка) и, если есть аксессуар, его `case` в `accessory()`. Система координат и что меняется по уровням ярости — в `references/portrait.md`. Цвета бери из `cat.palette` (`p.fur2` и т. п.), чтобы портрет оставался согласован с записью в `cats.ts`.

Если у кота тёмная маска на морде (как у `siam`), посмотри особые случаи `cat.id === 'siam'` в `ears()` и `eye()`: закрытый глаз на уровне 0 рисуется обводкой, которая на тёмной шерсти не видна.

### 6. Проверка

```bash
npm test            # tests/content.test.ts: регистрация, лапа найдена и 240×320, портрет без дыр; tests/strikes.test.ts: уникальный и корректный стиль
npm run typecheck
```

Затем визуально: `npm run dev`, кнопка 🎨 → вкладка «Кот» → карточка с портретом (уровень 1) и названием удара; выбери кота, тапай и смотри на лапу в покое, замахе и ударе, и как портрет звереет по уровням. Если браузерного инструмента нет, попроси пользователя посмотреть и перечисли, на что обратить внимание. В консоли dev-сборки есть `__dc.renderFace(level, __dc.CATS.find(c => c.id === '<id>'))` — вернёт разметку портрета для любого уровня 0–5.

### 7. Документация

Добавь строку в таблицу котов SPEC.md §7.1 (id, имя, внешность, палитра, лапа, портрет, удар); для тематического кота — ещё и в §20.1. SPEC.md в этом проекте — живой документ, его таблицы считают источником правды о контенте.

## Чего не делать

- Не использовать в спрайтах CSS-переменные для цвета шерсти, градиенты и `filter` — цвета в лапе захардкожены, стиль плоский (SPEC §7.3).
- Не менять геометрию общих слоёв лапы (круг кисти, линия предплечья, круги пальцев) ради «красоты» — см. п. 4.
- Не регистрировать кота вручную в обход скрипта без причины: пять мест легко пропустить, а `normalizeSave` тесты ловят, но только если прогнать.
