# Портрет: `renderFace(level, cat)` в `src/render/portrait.ts`

Портрет не хранится в SVG — он собирается функциями из палитры кота для каждого из шести уровней ярости. Для нового кота дорабатываются две функции: `markings(cat)` (обязательно: switch по `cat.id` исчерпывающий, без case не соберётся) и `accessory(cat, level)` (если есть головной убор).

## Система координат (viewBox 0 0 120 120)

| Элемент | Где | Чем задаётся |
|---|---|---|
| Фон-кружок | центр (60,60), r 58 | `BG_BY_LEVEL[level]`: от серо-голубого на уровне 0 до тёмно-красного на 5 |
| Уши | полигоны над головой, кончики ~y 10 | `ears()`; угол `EAR_ANGLE[level]` — прижимаются с ростом ярости; **не рисуются, если задан `accessory`** |
| Голова | эллипс (60,66) rx 40 ry 34 | `palette.fur` |
| Отметины | поверх головы, под глазами | `markings(cat)` — сюда идёт всё «породное» |
| Эффекты | вокруг головы | `effects()`: «Z» на уровне 0, капля пота на 3, шипы цвета `fur` на 4–5, молнии на 5 |
| Убор, задняя часть | над глазами | `accessory().behind` — шляпа, шлем |
| Глаза | (45,60) и (75,60), r ≈ 9 | `eye()`: закрыты на 0, расширенный зрачок на 2, щелевой на 3, красные белки на 4, сплошная заливка `palette.eye` на 5 |
| Брови | над глазами | `brows()`: появляются с уровня 2, наклон и толщина растут |
| Нос | треугольник (56..64, 72..77) | `palette.nose` |
| Усы | от x 36/84 к краям | `whiskers()`: опускаются на 4–5 |
| Рот | y 76..91 | `mouth()`: от чёрточки до оскала с клыками |
| Убор, передняя часть | поверх всего | `accessory().front` — очки, монокль |

## `markings(cat)` — примеры

```ts
case 'ginger':   // «M» на лбу полосками fur2 + светлая мордочка
  return `
    <path d="M46 36 l5 14 l5 -14 Z M55 33 l5 17 l5 -17 Z M64 36 l5 14 l5 -14 Z" fill="${p.fur2}"/>
    <ellipse cx="60" cy="82" rx="20" ry="12" fill="#FFF8EE"/>`;
case 'siam':     // тёмная маска на всю мордочку
  return `<ellipse cx="60" cy="76" rx="24" ry="19" fill="${p.fur2}"/>`;
case 'marine':   // полупрозрачная мордочка + шрам на щеке
  return `
    <ellipse cx="60" cy="82" rx="18" ry="11" fill="${p.fur2}" opacity="0.35"/>
    <path d="M32 64 l10 14 M30 70 l8 10" fill="none" stroke="${p.fur2}" stroke-width="2.5" stroke-linecap="round"/>`;
```

Типичный набор: пятно мордочки вокруг носа и рта `ellipse (60,82) rx 18 ry 11`, полоски на лбу между ушами (y 30–50), пятно на глазу `circle (45|75, 60) r 12` — рисуется под глазом, поэтому глаз остаётся читаемым. Используй `p.fur2`, а не новые захардкоженные цвета, кроме явно «предметных» (повязка, шрам).

## `accessory(cat, level)` — контракт

Возвращает `{ behind, front, keepEars? }`. Обе части оборачивай в `wrap(...)`, если убор должен наклоняться и подпрыгивать с яростью (`tilt = -EAR_ANGLE[level] * 0.35`, `lift = -3` на уровнях 4–5). Очки в `front` обычно не оборачивают — они держатся на носу (исключение — `shades` у `elman`: съезжают набок нарочно).

- Без `keepEars` уши не рисуются: это для шляп и шлемов, которые закрывают макушку. `behind` тогда закрывает верх головы: контур от (20,52) через (60,12) к (100,52) — как шлем `marine` или шапка `sherlock`. Для остроконечной шляпы см. `wizard`: тулья выше viewBox-центра, поля — эллипс (60,36) rx 46 ry 8.
- `keepEars: true` — для очков (`roundgold`, `shades`), усов (`beard`) и причёсок (`curls`): уши остаются и торчат из-за убора. Усы и борода разнесены нарочно: усы в `front` закрывают верхнюю губу, борода в `markings()` лежит под ртом, чтобы оскал на уровнях 3–5 был виден.
- Детали, зависящие от уровня, приветствуются: у шлема `marine` визор светится сильнее с ростом `level`.
- Новое имя убора добавляется в union `accessory?:` в `types.ts` — скаффолд делает это сам, если имени ещё нет.

## Тёмная шерсть

На шерсти темнее `lum < 60` (`isDark()` в portrait.ts: `coal`, `wizard`, `kama`) обводка `#1F1A17` не видна. Закрытый глаз на уровне 0 автоматически рисуется цветом `innerEar`; всё остальное, что должно читаться на тёмной голове (ресницы, родинка, губы), рисуй светлее фона: у `kama` ресницы лиловые `#B48EAD`, губы `#D81B60`.

## Карточка в шторке

`ui/skins.ts` рендерит `renderFace(1, cat)` в карточке 120×120 и подписывает `strike.name`. Проверь, что на уровне 1 (спокойный кот) портрет узнаваем без эффектов — именно его видит игрок при выборе.
