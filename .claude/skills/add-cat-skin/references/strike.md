# Стиль удара: `StrikeStyle` в `src/content/strikes.ts`

У каждого кота уникальный стиль (это проверяет тест). Стиль описывает позу замаха, кадры удара и возврата, траекторию сноса предмета и эффекты. `power` ∈ [0, 1] растёт с уровнем ярости (`powerOf(level)`: 0, 0, 0.25, 0.5, 0.75, 1) — всё в стиле должно «расти» вместе с ним.

## Поля

| Поле | Смысл |
|---|---|
| `id`, `name`, `hint` | id в `StrikeId`; `name` показывается в карточке кота («Удар: Тычок»); `hint` — одна фраза |
| `swingMs`, `backMs`, `swingEasing` | длительности (умножаются на `speedMul` уровня, на уровне 5 ×0.4 — удар длится ~25–35 мс) и easing удара |
| `impact: {x, y}` | точка удара в координатах сцены, около предмета: `OBJ_BASE = (180, 480)`, у существующих стилей x 180–186, y 424–452 |
| `speedAngle` | угол линий скорости в градусах (0 → вправо, 90 → вниз), `null` — без линий |
| `clawAngle` | угол следов когтей, `null` — без когтей (броня, палочка, щелчок) |
| `shakeMul` | множитель тряски камеры (0.5 деликатный … 1.6 тяжёлый) |
| `burstColor`, `minBurst` | цвет вспышки (по умолчанию жёлтый) и минимальная сила вспышки даже при `power 0` |
| `preImpact`, `wandTip` | эффект во время замаха: `'bolt'` — искры от `wandTip` (координаты сцены) к `impact`; `'ring'` — сжимающееся прицельное кольцо. Новый тип эффекта требует кода в `render/fx.ts` и ветки в `onTap` в `main.ts` |
| `impactFx`, `propTip` | частицы с предмета в лапе в момент удара: `'ash'` — хлопья пепла падают из `propTip`, `'splash'` — капли брюта разлетаются дугой (`Fx.propBurst`). `propTip` — положение кончика предмета **в позе контакта**, координаты сцены: при ударе лапа поворачивается против часовой вокруг (410,700) и растёт, поэтому предмет над кистью уезжает влево — у `wave` сигарета из (161,326) в покое оказывается около (96,352). Новый вид частиц — ветка в `propBurst` |
| `raised(power, lift = 0)` | CSS-transform позы замаха; `lift` — дополнительный подъём в градусах для «дыхания» в покое |
| `swing(power, from)` | кадры удара; первый кадр — ровно `from` |
| `back(power, to)` | кадры возврата; первый — поза контакта, последний — ровно `to` |
| `knock(power)` | `{dx, dy, rot, squash, lift?}`: куда и как летит предмет; `squash` — сплющить перед полётом (удар сверху); `lift` — отрицательный подъём в первой трети (магия) |

Лапа вращается вокруг `PAW_PIVOT = (410, 700)` (transform-origin уже выставлен), поэтому `rotate` в позах — это мах всей лапой из правого нижнего угла; `translate` двигает лапу целиком.

## Контракт (из `tests/strikes.test.ts`), для всех `power` ∈ {0, 0.25, 0.5, 0.75, 1}

1. `swing(p, from)[0].transform === from`, кадров ≥ 2.
2. `back(p, to)` начинается с `swing(...)[last].transform` и заканчивается ровно `to`.
3. `knock(1)` летит не ближе, чем `knock(0)` (`hypot(dx,dy)` ≥ 95 %), и вращается сильнее по модулю; `dx < 0`, `dy > 0` (влево-вниз, на пол).
4. `raised(1) !== raised(0)` и `raised(0, 3) !== raised(0)`.

## Шаблон (по мотивам `jab`)

```ts
const HOOK: StrikeStyle = {
  id: 'hook',
  name: 'Крюк',
  hint: 'Короткий боковой крюк',
  swingMs: 55,
  backMs: 120,
  swingEasing: 'cubic-bezier(0.5, 0, 0.9, 0.4)',
  speedAngle: 205,
  clawAngle: -30,
  shakeMul: 1.1,
  impact: { x: 184, y: 436 },
  raised: (p, lift = 0) => `translate(${f(10 - 8 * p)}px, ${f(24 - 6 * p)}px) rotate(${f(14 + 6 * p + lift)}deg)`,
  swing(p, from) {
    return [{ transform: from, offset: 0 }, { transform: hitHook(p), offset: 1 }];
  },
  back(p, to) {
    return [
      { transform: hitHook(p), offset: 0 },
      { transform: `translate(${f(16 - 8 * p)}px, ${f(30 - 6 * p)}px) rotate(${f(17 + 6 * p)}deg)`, offset: 0.6 },
      { transform: to, offset: 1 },
    ];
  },
  knock: (p) => ({ dx: -(170 + 90 * p), dy: 200 - 30 * p, rot: -(90 + 90 * p), squash: false }),
};
function hitHook(p: number): string {
  return `translate(${f(-30 - 4 * p)}px, ${f(-20 + 2 * p)}px) rotate(${f(-4 - 6 * p)}deg) scale(${f(1.05 + 0.06 * p)})`;
}
```

Подключение: добавь `'hook'` в `export type StrikeId`, константу — в `STRIKES`. Готовые стили для ориентира: `swipe` (мах сбоку), `jab` (прямой тычок), `slam` (сверху, со сплющиванием), `pump` (с откатом назад на 35 % удара), `spell` (лапа почти не двигается, искры и `lift`), `deduce` (щелчок без вращения, кольцо прицела), `wave` (ленивая отмашка, пепел), `toast` (взмах с бокалом, брызги), `cuddle` (мягкий шлепок сверху, `squash` + `lift`), `slash` (хлёсткий взмах с царапинами).
